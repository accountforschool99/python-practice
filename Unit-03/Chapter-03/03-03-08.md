# Unit 3 Chapter 3 Question 8 - 101 Pyramid (harder)

Create a program that uses a for loop to generate a pyramid of a certain height, using `1`s and `0`s.

<details>
  <summary>Hint</summary>

  Consider multiplying '10' as one of the ways of doing this question
</details>


## Input Specifications
The input consists of a single positive integer, $M$.

## Output Specifications
The output consists of a pyramid following the specific structure outlined in the sample output.

The first line should contain a singular `1`. Each proceeding line should have one more `1`, with `0`s separating them. This continues on until the final line, which contains $M$ number of `1`s. 

Hint: the number of leading whitespaces to print will require careful calculation. 

## Sample Input

```
4
```

## Sample Output

```
   1
  101
 10101
1010101
```
