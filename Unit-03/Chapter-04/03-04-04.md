# Unit 3 Chapter 4 Question 4 - Space Finder

Use a for loop to output the index of every space found in a user-inputted string, $S$.

## Input Specification

The input consists of one line, $S$, the user-inputted string. 

## Output Specifications

Output the indexes of every occurrence of a space character in the string $S$ onto a single line. Each occurrence should be separated by a comma, unless only one occurrence of a space occurs, then no comma should be printed.

If no spaces were found, then output `no spaces found`. 

## Sample Input 1

```
Awk! Cave of wonders!
```

## Sample Output 1

```
4, 9, 12
```

## Explanation for Sample Output 2
There are spaces at index 4, 9, and 12. Since more than space is present in the user-inputted string, they are separated by commas.

## Sample Input 2

```
hello world!
```

## Sample Output 2

```
5
```

## Explanation for Sample Output 2
As only one space is in the string `hello world!`, only index `5` without a comma is printed.

## Sample Input 3

```
hello
```

## Sample Output 3

```
no spaces found
```

## Explanation for Sample Output 3
No spaces are present in the string `hello`. Therefore, `no spaces found` is printed.
