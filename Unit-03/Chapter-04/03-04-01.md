# Unit 3 Chapter 4 Question 1 - Print All String Characters

Use a for loop to output each character in a user-inputted string, $S$, on its own line. 

## Input Specification

The input consists of one line, $S$, the user-inputted string. 

## Output Specification

Output each character or substring in $S$ on its own line. Spaces should also be printed onto their own line.

## Sample Input 1

```
hello world!
```

## Sample Output 1

```
h
e
l
l
o

w
o
r
l
d
!
```
