# Unit 3 Chapter 4 Question 3 - Every Other Character

Use a for loop to output every other character in a user-inputted string, $S$. Start from the first character in the string.

## Input Specification

The input consists of one line, $S$, the user-inputted string. 

## Output Specifications

Output every other character in the string $S$ onto a single line. Spaces are included.

## Sample Input 1

```
hello world!
```

## Sample Output 1

```
hlowrd
```

## Explanation for Sample Output 1
Starting from `h` and skipping by 2, the characters that are outputted are **h**e**l**l**o** **w**o**r**l**d**!

## Sample Input 2

```
Awk! Cave of wonders!
```

## Sample Output 2

```
Ak aeo odr!
```

## Explanation for Sample Output 2
Starting from the first letter `A` and skipping by two, `Awk! Cave of wonders!` becomes `Ak aeo odr!`
