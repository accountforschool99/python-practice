# Unit 3 Chapter 6 Question 7 - Multiplication Table (Hard)

Create a program that takes in an integer from 1-9 and prints a [multiplication table](https://en.wikipedia.org/wiki/Multiplication_table#Modern_times) without the row/column headers. The table needs to be aligned.

<details>
  <summary>Hint</summary>
  If your program doesn't work with the I/O testing, you might have trailing spaces at the end of each line. The output has no ending spaces!
</details>


## Input Specification
The input consists of a single integer, $J$, where $1 <= J <= 12$.

## Output Specification
The output consists of a multiplication table with J rows and J columns. The number in row $i$ and column $j$ is $i × j$. Print each row on its own line.

## Sample Input 1

```
4
```

## Sample Output 1

```
1 2  3  4
2 4  6  8
3 6  9 12
4 8 12 16
```

## Sample Input 2

```
12
```
